# Mobile is the primary platform; the wearable extension targets smart glasses, not a smartwatch

The brief lists "smartwatch/wearable cross-device experience" and "AR sightseeing" as
emerging tech to consider, without picking a form factor. We decided the primary prototype
targets mobile, with a second-phase wearable extension specifically for AR smart glasses
rather than a smartwatch. Smart glasses fit the AR/landmark-recognition angle the brief
already calls out as emerging tech, whereas a smartwatch would mostly duplicate mobile
notifications with a smaller screen. Phasing the wearable as a later extension (rather than
prototyping it alongside mobile) keeps the primary Figma deliverable within the team's
scope for a single semester.
