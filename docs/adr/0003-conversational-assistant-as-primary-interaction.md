# Conversational assistant is the primary interaction mode, not a secondary widget

The brief lists conversational AI as emerging tech to "consider," without requiring it be
central. We decided the voice-and-text Conversational Assistant is CapeScape's primary
interaction surface — the first thing a user engages with for recommendations, wayfinding,
and Q&A — rather than a browse/map-first app with a chat widget bolted on as an optional
helper. We considered the browse-first alternative and rejected it: it would relegate both
the AI value proposition and the accessibility case for visually-impaired users (who benefit
most from voice-first, non-visual interaction) to a secondary surface, undermining the
report's §3.4 AI Feasibility and accessibility arguments. This is a significant IA
commitment — it shapes the low-fi wireframes and is expensive to walk back once the
prototype's screens are built around it.
